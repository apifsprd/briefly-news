# System Design Document (SDD) — Briefly

**Nama Aplikasi:** Briefly — Minimalist Mobile-First Web News Aggregator  
**Versi Dokumen:** 1.0  
**Target Architecture:** Jamstack (ReactJS + TypeScript + Tailwind CSS) on Cloudflare Pages & Cloudflare Pages Functions  

---

## 1. Pendahuluan & Tujuan Sistem

**Software Design Document (SDD)** ini menerangkan arsitektur perangkat lunak, struktur komponen, aliran data, serta strategi antarmuka untuk aplikasi **Briefly**. Briefly dirancang khusus dengan pendekatan **Mobile-First**, menyajikan agregasi berita real-time dengan antarmuka monokrom minimalis yang bersih.

Sistem memanfaatkan teknologi web modern:
* **Frontend**: ReactJS + TypeScript + Tailwind CSS
* **Animations**: Framer Motion
* **Iconography**: FontAwesome Free Tier
* **Alerts & Modals**: SweetAlert2 (Monochrome Theme)
* **Backend Proxy / Edge Functions**: Cloudflare Pages Functions (Serverless Edge)

---

## 2. Arsitektur Tingkat Tinggi (High-Level Architecture)

Briefly menggunakan pola arsitektur **Serverless Jamstack**. Seluruh aset statis aplikasi di-host di Cloudflare Pages CDN global, sementara request pemrosesan data RSS ditangani oleh Cloudflare Pages Functions di Edge Network.

|  |  | Tailwind CSS      |  | Framer Motion     |  | FontAwesome Icons     |  |  |
|  |  | (Mobile-First UI) |  | (Smooth Modals)   |  | & SweetAlert2 Alerts  |  |  |

+----------------------------------------|----------------------------------------+

## 3. Desain Komponen & Antarmuka UI (Mobile-First Strategy)

### 3.1 Prinsip Layout Mobile-First
Layout dikembangkan menggunakan pendekatan **Mobile-First** dengan penyesuaian breakpoint Tailwind CSS:
* **Mobile View (`< 640px`)**: Header kompak dengan perataan satu kolom, bilah kategori bergeser horizontal (*scrollable chip filters*), kartu berita seluler penuh (*full-width card*), dan tombol aksi yang mudah dijangkau ibu jari (*thumb-friendly*).
* **Tablet View (`640px - 1024px`)**: Grid dua kolom untuk kartu berita.
* **Desktop View (`> 1024px`)**: Grid 3–4 kolom dengan sidebar navigasi kategori opsional atau top bar terstruktur.

### 3.2 Hirarki Komponen React
```
<AppProvider>           # Context API (ThemeState, FeedState, SearchState)
  <MainLayout>          # Container utama dengan dukungan Dark Mode
    <Header>            # Logo Briefly, Search Bar, Theme Toggle, FontAwesome Icons
    <CategoryFilter>    # Scrollable chip filter kategori & sumber berita
    <NewsFeedGrid>      # Grid kartu berita dengan animasi Framer Motion
      <NewsCard>        # Kartu berita individual (Judul, Sumber, Waktu, Excerpt)
    </NewsFeedGrid>
    <ReaderModal>       # Modal Reader Mode (Framer Motion AnimatePresence)
    <Footer>            # Informasi hak cipta & status sumber berita
  </MainLayout>
</AppProvider>
```

## 4. Integrasi Library Third-Party

### 4.1 Tailwind CSS (Styling & Mobile-First Layout)
* Utilitas CSS digunakan untuk memastikan performa *render* bebas hambatan (*zero runtime CSS cost*).
* Palet warna disesuaikan untuk monokrom murni:
  - `bg-white dark:bg-zinc-950`
  - `text-zinc-900 dark:text-zinc-50`
  - `border-zinc-200 dark:border-zinc-800`

### 4.2 Framer Motion (Mikro-Animasi & Transisi)
* **Reader Modal**: Menggunakan `AnimatePresence` dan `<motion.div>` dengan efek `initial={{ opacity: 0, y: 20 }}`, `animate={{ opacity: 1, y: 0 }}`, dan `exit={{ opacity: 0, y: 20 }}`.
* **Feed Stagger**: Efek kemunculan bertahap (*stagger children*) pada kartu berita saat kategori atau pencarian berubah.

### 4.3 FontAwesome Free Tier (Ikonografi Intuitif)
* Menggunakan paket `@fortawesome/react-fontawesome` dan `@fortawesome/free-solid-svg-icons`.
* Ikon terintegrasi: `faNewspaper` (Logo), `faSearch` (Pencarian), `faSun` / `faMoon` (Dark mode), `faArrowUpRightFromSquare` (External link), `faXmark` (Tutup modal), `faSync` (Refresh feed).

### 4.4 SweetAlert2 (Monochrome Alerts & Error Handling)
* Di-wrap dalam utility helper (`src/utils/alert.ts`) agar sesuai dengan estetika monokrom (hitam-putih).
* Digunakan untuk:
  - Peringatan kegagalan fetching RSS (misalnya penerbit offline).
  - Informasi pencarian tidak ditemukan.
  - Peringatan koneksi internet terputus.

## 5. Alur Data (Data Flow & Sequence)

```
[User] -> (Select Category / Search) -> [React Client]
                                             |
                                    Check Local State Cache
                                             |
                                  (Cache Miss or Refresh)
                                             |
                                             v
                              Fetch /api/feed?url={rss_url}
                                             |
                                             v
                              [Cloudflare Pages Function]
                                             |
                                    Fetch External XML
                                             |
                                     Parse XML to JSON
                                             |
                                Return JSON Response (200 OK)
                                             |
                                             v
                             [React Client] Updates State
                                             |
                              Render Feed via Framer Motion
```

## 6. Penanganan Kesalahan & Ketahanan Sistem (Resilience & Error Handling)

1. **CORS Error Prevention**: Semua permintaan RSS eksternal dilewatkan melalui `/api/feed` Cloudflare Pages Function. Client tidak pernah memanggil URL RSS secara langsung.
2. **Fallback Feed**: Jika salah satu sumber RSS mengalami kegagalan (*HTTP 500 / Timeout*), Cloudflare Function mengembalikan status JSON error bersih, dan SweetAlert2 menampilkan toast peringatan non-blocking kepada pengguna tanpa menghentikan feed dari sumber lain.
3. **Empty Search State**: Jika kata kunci pencarian tidak cocok dengan judul mana pun, komponen `NewsFeedGrid` menampilkan ilustrasi minimalis dan pesan yang relevan.

---

## 7. Desain Keamanan & Aksesibilitas (Security & Accessibility)

* **Content Sanitization**: Ringkasan/deskripsi HTML dari XML RSS dibersihkan menggunakan pembersihan string aman sebelum ditampilkan di Reader Mode untuk mencegah serangan XSS (*Cross-Site Scripting*).
* **Keyboard & Touch Accessibility**: Reader Modal dapat ditutup dengan menekan tombol `ESC` atau menotok area luar modal. Focus trap diterapkan pada perangkat seluler.
* **Contrast Compliance**: Seluruh warna teks dan tombol monokrom memenuhi standar visibilitas WCAG AA (kontras minimal 4.5:1).
